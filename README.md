# FTDiffyybot - Image to Base64 Telegram Bot

FTDiffyybot (`@FTDiffyybot`) is a fast, lightweight, and secure Telegram bot designed to encode uploaded images into Base64 strings and Data URIs for use in web development, CSS, HTML, and APIs.

## Features

- **Format Support:** Converted formats include JPG, PNG, WEBP, GIF, and BMP.
- **Dual Send Methods:** Upload images via standard photo options or uncompressed document files.
- **Dynamic Output Handling:** Sends raw Base64 directly in messages for smaller files, or packages large outputs into a downloadable `.txt` file when Telegram limits are exceeded.
- **Privacy Enforcement:** In-memory execution ensures no images, user records, or Base64 data are retained on disk.
- **Size Validation:** Enforces a strict 20 MB size ceiling.
- **Long Polling Architecture:** No webhooks or complex web server deployments required.

## Creating a Telegram Bot

1. Open Telegram and search for `@BotFather`.
2. Send `/newbot` and follow the prompts.
3. Set the display name to `FTDiffyybot` and the username to `FTDiffyybot`.
4. Copy the API Token generated by BotFather.
